# Data & Analytics Wiki

## Purpose

The purpose of this wiki is to enlist the common standards and guidelines for developing Data Vault models and transformation logic at FBIN Data & Analytics using dbt, Snowflake, SQL, and software engineering practices.

The goal is to provide a set of guidelines that introduce consolidated, governed, and consistent efficiencies in the overall Data Vault and dbt development projects at FBIN. This wiki lays out how a few of the development tools and concepts that should be built.
